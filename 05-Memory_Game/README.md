# Memory Matching Game

A memory-based card matching game built with Python and Pygame. Find matching pairs of cards and compete against the computer or another player.

## Features

* Single-player mode against the computer
* Two-player mode
* Three difficulty levels: Easy, Medium, and Difficult
* Animated card flips and matching effects
* Custom-drawn card illustrations
* Background music and sound effects
* Score tracking and result screen

## Requirements

* Python 3
* Pygame

## Run the Game

Install Pygame:

```bash
pip install pygame
```

Run the game:

```bash
python memory_game.py
```

## Controls

* **Mouse:** Navigate menus and select cards.
* **Click:** Flip a card and find its matching pair.

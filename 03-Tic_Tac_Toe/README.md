# Tic Tac Toe

A desktop Tic Tac Toe game built with Python and Pygame, featuring an interactive interface, smooth animations, and an AI opponent powered by the Minimax algorithm.

## Features

* **Two Game Modes:** Play against the computer or another player.
* **AI Opponent:** Uses the Minimax algorithm to select optimal moves.
* **Symbol Selection:** Choose to play as X or O.
* **Interactive UI:** Smooth animations, hover effects, and dynamic background colors.
* **Win Detection:** Highlights the winning combination.
* **Confetti Animation:** Celebrates victories with a visual effect.
* **Game Controls:** Restart the game, return to the main menu, or exit.

## Requirements

* Python 3.10 or later
* Pygame

## Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <project-directory>
   ```

3. Install the required dependency:

   ```bash
   pip install pygame
   ```

## Usage

Run the following command to start the game:

```bash
python tic_tac_toe.py
```

## Controls

* **Mouse:** Navigate menus and select board cells.
* **ESC:** Return to the main menu.
* **Exit Button:** Close the game.

## Technologies Used

* Python

* Minimax Algorithm

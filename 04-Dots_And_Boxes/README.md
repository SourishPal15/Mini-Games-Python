# Dots & Boxes

A classic Dots & Boxes game developed using Python and Pygame, featuring single-player and two-player modes with multiple difficulty levels.

## Features

* **Game Modes:** Play against the computer or another player.
* **AI Difficulty:** Easy, Medium, and Hard.
* **Board Sizes:** Small, Medium, and Large.
* **Sound Effects:** Audio feedback for in-game actions.
* **Settings:** Customize board size and toggle sound.
* **Game Controls:** Pause, resume, and restart.
* **Scoreboard:** Track scores and current turns.
* **Visual Effects:** Animations, hover effects, and confetti.

## Requirements

* Python 3
* Pygame

## Installation

Install Pygame using pip:

```bash
pip install pygame
```

## How to Run

Run the following command in your terminal:

```bash
python dots_and_boxes.py
```

# Flappy Bird

A classic Flappy Bird game recreated using Python and Pygame. Control the bird, navigate through obstacles, and try to achieve the highest score without hitting the pipes.

## Features

* Smooth bird movement and flap animations.
* Randomly generated pipes with varying gaps.
* Increasing difficulty as the score increases.
* Main menu, pause screen, and game-over screen.
* Sound effects generated programmatically.
* Particle effects and visual animations.
* Local high-score storage using JSON.

## Controls

| Key              | Action         |
| ---------------- | -------------- |
| Space / Up Arrow | Flap           |
| Left Mouse Click | Flap           |
| P / Esc          | Pause / Resume |
| Up / Down Arrow  | Navigate menus |
| Enter            | Select         |

## Requirements

* Python 3.x
* Pygame

Install Pygame:

```bash
pip install pygame
```

## How to Run

```bash
git clone <repository-url>
cd Flappy-Bird
python flappy_bird.py
```
